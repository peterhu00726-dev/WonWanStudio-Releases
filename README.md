# WonWan Studio — Public Releases

Copyright (c) 2026 WonWan Studio contributors. See the release package notices.

This repository hosts public WonWan Studio release assets only. Product source code remains in the private [`WonWanStudio`](https://github.com/peterhu00726-dev/WonWanStudio) repository. The default branch does not distribute installers.

## Download

There is no approved public installer yet. Do not install packages from development caches, test fixtures, or unsigned build directories.

The website's stable Windows download URL is:

`https://github.com/peterhu00726-dev/WonWanStudio-Releases/releases/latest/download/WonWanStudio-x64.msi`

That URL becomes usable only after an approved release includes the exact asset `WonWanStudio-x64.msi`. Each public release must include the signed `manifest.json` and `artifact.sig.json` used by the in-app updater. The versioned release, updater feed, and stable website URL must resolve to the same package hash and version. A new release is not announced until the public asset URL is fetched and verified.

## Test status

This repository is a future public asset host, not evidence that the application is complete, signed, legally reviewed, or ready for general use. Public test releases must identify the tested feature scope, known limitations, installer signature status, SHA-256, and data-backup guidance. No purchase, telemetry, or hidden upload is provided here.
